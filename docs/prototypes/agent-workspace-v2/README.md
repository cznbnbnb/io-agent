# iO Agent 界面原型 · 2026-10-23

范围：仅 Web 设计预览。所有人物、问题、连接、电量、资料与回执均为合成数据；不连接真实眼镜、电脑、资料服务器，不修改 Android App。当前录音故障已由用户交给另一任务。

## 现状依据

- `TurboAddon.install`：右上方 112 × 44 的 iO Agent 悬浮按钮，打开 `AgentWorkspace` 全屏 Dialog。
- `AgentWorkspace`：眼镜连接、电脑任务、资料同步、眼镜任务卡、原有工具、账号云服务、固件状态、一分钟测试、诊断同时出现。
- `TaskWorkspace`：任务、问题、回执、会话导入、切换、暂停、过期移除混在纵向列表；已有折叠历史修补，但入口层级仍未分开。
- `MaterialWorkspace`：连接参数、队列技术状态和同步操作同时占据首屏。
- `EditorialUI`：背景 #17131B、表面 #221D25、按钮 #DBF67A；嵌套大圆角卡和等权大按钮造成信息膨胀。
- 原厂 1.0.7 解包资源 `rayneo_v2/images/common`：`icon_memory_sel.svg` 等使用 #02A97B，未选中图标为白色约 90% 不透明；`glasses_home_bg.webp` 从 #104D3F 渐至 #010101；普通设置面板 #1C1C1C，圆形功能底 #323232。依据 SVG 源码及像素读取，不是完整原厂界面实测。图片分析技能的两家服务返回 401，未以识图服务成功作为证据。本原型中的宿主页是风格示意，不是原厂截图。

## 设计计划（编码前）

颜色：原先草拟浅色，核对原厂资源后改为近黑底 #0D100F、深灰内容 #1B201E、主文字 #F0F3F1、次文字 #99A49D、原厂青绿 #02A97B、淡青绿 #36C49B。主动作使用青绿底与深色字。外围评审画布保留浅灰，突出手机内的真实界面方向。

字体：系统中文无衬线（PingFang SC / Noto Sans CJK / Microsoft YaHei）；页面标题 27、正文 15、辅助 12–13 px。字号和间距以手机阅读为主，不复制网页管理台。

布局：悬浮按钮是入口；打开单一工作区并由内部导航管理任务、资料、设置，关闭可恢复到原页面。首屏先展示需要用户答复的问题，其余任务压缩成行；每屏只有一个最强动作。

```
原厂页面 → 悬浮 Agent → Agent 工作区
                         ├ 任务 → 问题 / 任务详情 → 回复 → 回执
                         ├ 资料 → 日期 / 同步 → 资料详情
                         └ 设置 → 电脑连接 / 眼镜提醒 / 扩展工具 / 开发者选项
```

评审修正：不做大号数据看板、额外独立品牌首页或并排同权九宫格；避免让诊断、版本号、协议和测试卡成为日常流程。Android 以独立容器承载；“集成入口”仅演示后续鸿蒙在相同内容上替换入口的可能性，不承诺无适配移植。

## 本地预览

在本目录执行 `python3 -m http.server 8765 --bind 127.0.0.1`，浏览器打开 `http://127.0.0.1:8765/`。也可直接打开 `index.html`，无构建或在线依赖。

可点击：悬浮入口、三个主分区、任务筛选、完整回答与回执、暂停任务并追加指示、默认 Agent 与工作区、委托任务、资料日期与正文、同步设置、原音保存与文档导出、连接详情及暂停/恢复、提醒设置、开发者区域、窄屏与集成入口模式。所有操作只改变浏览器内存；回执与导出均为演示，不发送真实指示，也不生成真实音频或文档。

`assets/glasses.png` 取自本地原厂 APK 的 `rayneo_v2/images/pairing/rayneo_s3_sideview_device_list.png`，只供此本地设计预览使用，版权归原权利人；没有重新分发 App 或发布到公网。

## 后续落地边界

先由用户评审视觉和路径，再单独迁移 App。工作区的页面路由与宿主入口分离；设备状态、任务、资料等依赖通过适配层接入。远程更新需要版本兼容、签名、失败回退等独立设计，不能仅凭这个静态原型承诺“替换悬浮窗即可支持任意原厂版本”。

## 第二轮：九条浏览器反馈与修正

| 反馈 | 本轮原型修正 |
| --- | --- |
| 1. 连接列表的查看、暂停、恢复入口不统一 | 每条连接均为「查看连接」；进入详情后再暂停、恢复或设置默认目标。暂停连接与暂停任务分开表达。 |
| 2. 缺少暂停任务并指示的操作 | 任务增加「暂停并指示」；追加指示后先请求暂停，收到 Agent 回执才显示已暂停，再由用户选择按新指示继续。 |
| 3. 应有默认 Agent 和默认工作区 | 增加默认目标设置，新委托自动带入；导入连接时可演示设为默认。已有问题仍回复原任务。 |
| 4. 切换任务筛选时页面高度变化 | 筛选结果区域固定 240 px，超出后内部滚动；切换时保留外层滚动位置。 |
| 5. 自动同步含义与时间不清楚 | 首页改为「查看进度」，显示最近成功、下次同步及等待原因；「立即同步」收在进度页。自动节奏见下方暂定方案。 |
| 6. 日历缺少记录标记 | 有记录的日期加圆点和图例；圆点表示存在资料，不表示同步状态。 |
| 7. 缺少远程原音保留和手机导出 | 详情增加原音状态、到期时间与「保存原音到手机」；另设「导出文档」并演示 Word、Markdown、纯文本格式。 |
| 8. 资料同步只有开启摘要，无法关闭 | 设置详情增加明确开关；关闭时保留已有资料与待同步队列，重新开启后继续。 |
| 9. 原厂入口按钮措辞不准确 | 改为「回到原厂 APP」。 |

### 已确认的需求与暂定方案

- 用户已确认：远程原音固定保留 **3 天**，本阶段不提供时长调整；原音和文档均需保存到手机。
- 计时方案暂定为：原音在远程保存成功后起算 **72 小时**；展示明确到期时间。手机导出副本不随远程到期删除。
- 当前 App 的资料同步仍由用户手动触发。原型中「稳定文字每 1 分钟合并上传、完整原音片段保存后上传、断网保留队列并补传」是下一版暂定方案，尚未接入 App；最近成功时间拟仅在服务器确认后更新。
- 默认 Agent 与工作区只在本原型中流转。CLI 登记默认目标、眼镜主动唤起调用默认 Agent，以及真实任务暂停/继续回执均待实现；默认目标不可用时不自动投向其他 Agent。
- 所有同步成功、回执、保存与导出均为演示。原型不证明真实后端已保留原音，也不执行文件下载。

### 本轮已完成的浏览器验证
