# Android 智记自动同步

2026-10-24 dev73 已装机、分块/续传服务已启用；正式资料凭据未续签。

## 调度与范围

沿用资料同步的明确开关及已登记账号/服务器。关闭、凭据过期、未登录或账号不符时不读原厂、不上传，也不自动签发凭据。正文读取页面独立工作，不以允许上传作为查看本机智记的前提。

进程启动后恢复调度，正常每分钟检查一次，串行执行。每轮读取今天和一个补查日期：首次是昨天；中断后从已完成日期继续逐日补查。首次启用之前的更早历史仍由用户按日期/月选择。成功轮次才推进补查日期，空列表只说明本轮未取得正文，不会生成删除。

调度写盘后才开始网络工作，进程重启不会绕过间隔。失败按 1、2、4、8、15 分钟退避；系统网络恢复通知可提前重试，但距上次尝试至少 30 秒，正常成功轮次仍保持一分钟。时钟回拨不会永久冻结任务，换时区重新从当地昨天起查。每轮有两分钟执行上限，暂停立即取消正在进行的网络请求；分块与未知回执留待下一轮对账。

自动上传可以在后台继续。页面读取和内容回调仍要求前台与原账号，不能因为后台上传获准而把旧页面内容显示出来。Android 挂起或终止进程会延迟执行，不承诺强制绕过系统后台策略；待真机验证恢复行为及调度延迟。

最近成功时间来自资料存储回执。来源读取失败、队列未清空或仅上传了分块均不更新成功时间。自动错误与本机资料读取错误分开，仍保留手动重试入口。

## 已确认历史占用

发送队列只对以下旧版本收缩完整发送副本：该版本有校验通过的服务器回执，同一资料另有更新版本的有效回执，而且没有保留中的修复依赖它的正文。最新版本、未确认版本、需要对账的版本均不收缩。

保留旧 event ID、修订号、载荷哈希、续签/修复别名及服务器回执。崩溃后旧日志重放只匹配这些证据，不重新发旧 POST；同版本不同内容仍拒绝。随后才收缩来源日志中的对应发送快照，保留初始版本归属。两个文件之间崩溃可恢复。

当前载荷合计上限 16 MiB，原子状态文件上限 32 MiB，历史回执最多 16,384 条。超限明确停止，不静默清除最新资料。默认其他业务的 `AtomicDocument` 上限仍是 8 MiB。队列 schema 4、来源日志 schema 2；旧 dev72 不直接读取它们。新版使用独立目录，回退继续读取保留的旧目录，详见下节。

## 断网期间正文增长

已补服务器原子确认/撤销旧发送。旧版本若已入库，保留回执并生成下一修订；若未入库，先持久阻止旧事件迟到提交，再以最新正文替换同一待上传修订。一次 404 本身不允许替换。丢撤销回执后按原 event 对账；替换意图与队列之间崩溃可重放。详见[长资料传输契约](material-transfer-v1.md)。

旧服务未声明 `material_cancel_v1`、撤销结果未知、已有待确认的旧版计数修复依赖或达到保留上限时，仍保留原队列并明确停止。每轮最多处理 16 个未确认事件，已经确认撤销的事件不重复占本轮处理名额。每个修订最多保留 16 次撤销证明；不以无限重试代替容量边界。

## 升级与回退

新版发送队列、导入日志和修订日志保存在 `material-accounts-v2/<账号>`；旧 `material-accounts/<账号>` 的三份状态保持原样。本机阅读库继续使用原路径和原格式，完整正文仍可由 dev72 读取。迁移先持久记录来源哈希和 copying 意图，再复制，核对完成后标 ready；中途失败重试同一份来源，不能覆盖无主新状态或丢失的已确认迁移文件。

新加密配置写 `material_sealed_v2`，与旧 `sealed` 中的暂停投影一次提交，并保留最初旧密文。回退版默认暂停资料同步，可读取旧目录；新版期间的完整新资料继续保留在新目录，旧版不显示这些上传状态。再次升级核对旧目录和旧配置：旧读取器正常状态整理可接受；用户在回退版新增发送内容、续签或改开关时明确停止，需对账后恢复，不悄悄忽略旧版操作。密文校验失败不会回退到旧配置。

该机制只保留并隔离资料状态，不会降级覆盖手机 APK，也不自动恢复旧数据库；实际 APK 回退仍遵守 Android 安装限制。42 项文件迁移测试使用真实 dev72 读取器的独立 JVM，包含长篇本机正文；24 项配置测试使用真实 AES/GCM 和内存偏好存储边界。Android Keystore 与升级前后手机文件验证另记真机证据。
