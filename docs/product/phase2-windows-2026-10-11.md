# P22 短窗转写与检查点开发

日期：2026-10-11。0.1.27 追加，建立在 `c81de1b` / 0.1.26 的资料修订和耐久队列之上。当前为隔离验证核心，未启用日常短窗调度。

后续状态：0.1.28 候选已接入日常协调器，见 [日常短窗调度记录](./phase2-daytime-transcription-2026-10-11.md)；本文保留0.1.27的验证范围，不据此推断新协调器已通过真机共存或全天验收。

## 实现

`AsrWindows` 按互不重叠的核心帧范围推进；识别时读取前后上下文，按语音片段时间中点决定归属。`AsrWindowStore` 将每窗文字不可变落盘，游标从连续的已提交窗口推导；写盘中断的 partial 文件不前进游标，损坏/缺口拒绝继续，不静默跳过。

`LifelogASR.transcribeWindow` 在真实 Worker 内执行；请求包含游标、核心/上下文长度、是否封口及上轮原音前缀校验。返回原音时间轴和下一游标。OGG 只接受完整、CRC/序列/格式符合当前智记配置的页，增长中的末尾半页留到下次；已封口文件必须完整。恢复时重新核对之前读取的前缀 SHA256，音频改变则停止拼接。

为确保 Opus 状态一致，当前每窗先重放前缀解码，再只识别所需范围；不保存依赖本机 ABI 的原生解码状态。读取上限 16MB、帧上限 60000，单窗调用有响应期限。重放开销须在长段实测后决定缓存优化，不能凭短样本推断全天预算。

隔离入口每次只运行一个20秒核心窗口、前后各最多12秒上下文，检查点单独保存在测试目录。重启不自动推理，需明确继续。原始双声道、旧文字、日常资料和服务器均不修改；语音聚类仍为窗口内匿名结果，跨窗身份关联未启用。

## 验证与限制

- 本地回归：页未写完、已提交页损坏、相邻窗口边界归属、时间轴还原、原音前缀变化、检查点崩溃、取消后迟到结果均覆盖。最新应用 413 项、契约 5 项通过，鸿蒙构建通过；不以测试数量代替产品验收。
- 真机 0.1.27：同一份已保存59.28秒样本，三个真实 Worker 窗口依次提交 0→1000→2000→2964 帧，耗时2244 / 3632 / 3105ms。窗口间两次强制结束本应用并重新启动，进程26863→31575→32854；每次明确加载模型和点击继续，未自动重跑已提交范围。三个检查点的原音前缀校验一致。再次点击直接返回 already_complete，游标不变且未调用识别。证据见 [真机窗口摘要](../../rebuild/phase1/device-p22-window-regression.json)，真实文字和聚类向量仅留私有忽略目录。
- 上述为充电100%、前台、后台蓝牙资格有效、起始热等级0的隔离样本验证；单窗起始采样不代表完整热趋势。尚未并行采集，未检验未充电功耗、词句准确率或跨窗人物身份，不能据此宣布全天智记通过。
- 当前完整段日常调度仍沿过渡充电门槛。真实预算信号已具备，但尚未接入短窗周期；不能称 P22 已完成或未充电体验已支持。
- OGG 持续写入的手机采集、热限、低电、系统收回、8小时功耗和正式同步均待验。真实对话边界词句、跨窗口重复/漏字与说话人精修质量仍需标注样本；数学上不重叠的窗口归属不等于识别文本已无漏字。

## 紧接着的接入范围

1. 在采集页提交后提供稳定 started/帧数/完整前缀观察，保持10分钟原音归档独立；不为提早出字缩短或重置眼镜采集会话。
2. 用窗口检查点作为日常队列的恢复游标，原音前缀更新可追加，替换或回退拒绝；每窗产生资料修订，迟到结果受用户更正和删除保护。
3. 接真实电量/热/空间/后台资格；每分钟限制 Worker 实际耗时，剩余预算不足延后；指令优先，不能以 forced 绕过热和存储护栏。模型加载、超时重建和前缀重放均计入预算。
4. 展示积压原因、原音已保存和已转写覆盖，区别等待音频/系统限制/冷却/失败待重试；原音清理仍须符合留存和可靠上传规则。
5. 完成孤立真机回归后，回归日常智记、主动录音、助手插入/恢复和后台场景；充电精修作为独立后续修订，不覆盖用户校正。
