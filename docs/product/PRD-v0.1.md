# 雷鸟 iO PRD 当前入口

原 v0.1 的产品定位已按用户 2026-10-10 的纠正重写。请以 [当前 PRD](./PRD.md) 为唯一有效需求文档，实施顺序见 [开发顺序与阶段验收](./DEVELOPMENT-PLAN.md)。

本版已明确：官方基础体验是正式交付底线；手机负责语音转写入口；自有服务器负责存储、查询与消息中转；本地 Agent 负责综合日常资料和办公消息、执行任务；眼镜支持接收决策请求及选择/语音回复；原厂固件优先，采用鸿蒙原生美学与多设备适配。

旧版“基础功能后补”“服务器负责主要智能处理”“录音链路需从零验证”等方向不再适用。已实现的录音和硬件接口按用户最新说明复用。
