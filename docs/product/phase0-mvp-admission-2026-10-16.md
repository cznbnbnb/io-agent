## 普通页面保留的路径

集中准入位于`MvpAvailability.ets`，只有明确登记的ID可用，未知ID默认关闭；返回的登记副本不能改写实际准入。证据及适用边界随ID保存。准入不由临时连接状态或是否填写凭据决定，已验证路径遇断连显示真实状态。

| 入口 | 本批行为与范围 |
| --- | --- |
| 首页 | 连接、电量、录音、记录回顾、待办与资料；已连接主按钮进入录音 |
| 记录 | 现有手机/眼镜录音接收、开始/停止保存、本机转写、原音及当前文字导出、正常删除 |
| 资料 | 按日期回看既有录音/智记，查看和校正文字、导出；历史对话/稿件保留只读浏览和导出 |
| 待办 | 现有新增/发送、查询和在线单条删除；读取历史删除记录。原眼镜未连接时不显示远端删除发起按钮，确认弹窗返回后再次核对连接；从未发送的本机条目仍可本机删除 |
| 设置 | 已保存眼镜恢复连接、现有短时后台连接、外观；设备电量/状态/设置读回及已验亮度控制。自动校时继续沿用已人工确认格式 |
| 文字同步 | 保留已有文本同步配置、状态和普通同步路径；不宣称原音上传、无限积压或自动凭据轮换 |

首次配对、全天智记/定时启动、新播放器/原句定位、新资料搜索/总结/附注、稿件编辑、未验硬件设置、任务/眼镜收音、导航/天气/卡片/通知等未准入操作均不在普通界面提供。已确认的手动提词和手动通知历史证据保留，当前完整路径仍有缺口，依MVP稿后续逐项开放；隐藏不是从PRD删除，也不表示这些能力从未实现。

## 从所有入口和启动处落实

- `FeatureCatalog`、首页主操作/功能格、窄屏标签、宽屏侧栏、设置跳转使用同一规则；`openFeature`和内容渲染同时校验，未知路由不再落入导航页。
- 记录/智记里的播放、总结、搜索、说话人变更/拆句、清理空段以及同步恢复按钮分别关掉；已有播放的停止、既有采集的结束、未决记录的读取继续保留，隐藏不会清理数据。
- 资料页的普通录音转写统一进入既有本机队列；云端转写入口关闭，不在不同页面暗中采用不同的上传路径。
- `ConnectedServices`不再按旧配置自动开启助手待命或天气写入；当二者未准入时，录音接收直接初始化，不等待模型/天气凭据库。
- `AppRuntime`读取智记历史时不恢复全天/定时收音意图，不覆盖原配置文件；正常录音转写队列继续运行，自动总结关闭。
- 任务服务仍保存原草稿、来源和发送账本；普通页无新任务入口，自动口述交接和自动答复预览卡关闭。原卡清理、断连处理和已有持久队列的原有保护没有删除。
- 开发CLI及独立实验代码保留各自的身份、期限、占用和确认守卫；CLI存在不等于普通界面开放。
